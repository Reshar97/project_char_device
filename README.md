Драйвер символьного устройства my_buffer

Это учебный проект: драйвер символьного устройства для ядра Linux, реализующий кольцевой (циклический) буфер.Драйвер создаёт виртуальное устройство /dev/my_buffer, работающее как буфер фиксированного размера (1024 байта).  
1. Описание проекта

Драйвер поддерживает операции чтения, записи и управления через ioctl.Реализованы интерфейсы мониторинга состояния в /proc и /sys.  
2. Сборка и установка

Для сборки и управления модулем используется система make.  

Предварительные требования:Установите заголовочные файлы ядра:  

    sudo apt-get install build-essential linux-headers-$(uname -r)

Команды:  

Сборка модуля:

    make

Загрузка модуля в ядро:  

    sudo make install

Выгрузка модуля из ядра:  

    sudo make uninstall

Очистка проекта:  

    make clean

3. Использование устройства /dev/my_buffer

После загрузки модуля в системе появляется устройство /dev/my_buffer.  

Запись данных:  

    echo "Привет, ядро!" > /dev/my_buffer

Чтение данных:  

    cat /dev/my_buffer

Проверка логов ядра:  

    dmesg | tail -n 20

4. Интерфейсы мониторинга состояния
4.1. /proc/my_buffer

Драйвер предоставляет интерфейс для мониторинга состояния буфера.  

Команда:  

    cat /proc/my_buffer

Пример вывода:  

    --- Состояние кольцевого буфера ---
    Занято: 15 байт
    Свободно: 1009 байт
    Read Ptr: 0
    Write Ptr: 15

4.2. /sys/class/my_class/my_device/

Каталог в файловой системе sysfs, содержащий служебные атрибуты устройства.  

    dev — содержит главные и второстепенные номера устройства (например, 250:0).  
    uevent — служебная информация о событиях устройства.  
    Другие файлы — дополнительные метаданные, предоставляемые ядром.

5. Управление через ioctl

Для управления параметрами драйвера (получение размера, очистка буфера) необходимо использовать пользовательское приложение на языке C.  

В папке проекта лежит файл test_buffer.c — это готовая интерактивная консоль для тестирования всех функций драйвера.  

Компиляция тестового приложения:  

    gcc test_buffer.c -o test_buffer

Запуск:  

    ./test_buffer

В консоли доступны команды:  

    write <текст> — записать строку в буфер  
    read — прочитать всё содержимое буфера  
    size — получить общий размер буфера  
    used — получить количество занятых байт  
    free — получить количество свободных байт  
    clear — очистить буфер  
    exit — выйти из программы

6. Структура проекта

    char_dev.c — исходный код модуля ядра.  
    my_buffer_ioctl.h — заголовочный файл с кодами команд ioctl.  
    test_buffer.c — тестовое приложение для пользователя.  
    Makefile — скрипт для сборки модуля и приложения.  
    README.md — текущая документация.
